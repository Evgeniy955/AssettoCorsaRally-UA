# Українська локалізація Assetto Corsa Rally

Український переклад тексту гри. Озвучення штурмана залишається мовою, яку ви обрали в грі.

## Сумісність

| Переклад | Перевірена версія гри | Стан |
| --- | --- | --- |
| `0.6-UA-r2` | `0.6` | Перевірено на Steam build `25170642` |
| — | `0.7` | Файли локалізації змінилися; переклад для `0.6` не встановлюється |

Новий Steam build сам по собі не блокує встановлення: інсталятор перевіряє фактичні ресурси локалізації. Якщо вони змінилися, він зупиняє встановлення. Остання перевірка локальної версії `0.7` (build `26756580`) виявила зміну англійського `Game.locres` або `Game.locmeta`.

## Завантаження

Поки що опубліковано [AC-Rally-UA-Installer-0.6.8.exe](https://github.com/Evgeniy955/Games-translate/releases/download/acr-v0.6.8/AC-Rally-UA-Installer-0.6.8.exe) для перевіреної локалізації `0.6-UA-r2`.

SHA-256: `91C7E84AC091BF6EEEAD2829A71DFE31DA8CB2AF6895AE790B7F9B34A91495E3`.

Наступні перевірені версії публікуватимуться в [Releases цього репозиторію](https://github.com/Evgeniy955/AssettoCorsaRally-UA/releases). Попередні інсталятори залишаться в старому архіві.

Перед встановленням повністю закрийте гру. Запустіть EXE, перевірте знайдену папку Assetto Corsa Rally та натисніть **ВСТАНОВИТИ ПЕРЕКЛАД**. Для повернення оригінальних файлів скористайтеся кнопкою **ВІДНОВИТИ ОРИГІНАЛ**.

## Підтримка

Локалізація безкоштовна. Якщо хочете підтримати її подальше оновлення, доступна [добровільна підтримка через monobank](https://send.monobank.ua/jar/AXikLhaYGp). Донат не надає платного доступу чи додаткових переваг.

Про помилки перекладу можна повідомити через [Issues](https://github.com/Evgeniy955/AssettoCorsaRally-UA/issues).
